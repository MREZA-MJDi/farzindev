# Iran province and city source data

The bundled `iran-provinces-cities.json` dataset is derived from:

- Source repository: https://github.com/sajaddp/list-of-cities-in-Iran
- Release / dataset version: 3.1.2
- Official administrative source year: 1404 (Solar Hijri)
- Included records: 31 provinces and 1,481 records from the source's `cities-filtered` projection.

The filtered projection intentionally excludes the 191 separately-derived urban-zone records and keeps city records only. It also avoids confusing a county (`شهرستان`) with a city (`شهر`).

The source project notes that its output is prepared from the official administrative-divisions workbook through the end of 1404 and is not a substitute for legal citation to the relevant Ministry of Interior records.
